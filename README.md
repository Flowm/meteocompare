# MeteoCompare

Multi-model weather forecast comparison with a weighted aggregate and a confidence score, powered entirely by [open-meteo.com](https://open-meteo.com). Frontend-only — no backend needed.

## Develop

```bash
npm install
npm run dev
```

## Test

```bash
npm test
```

## Build

```bash
npm run build
```

## Stack

- Vue 3 + Vite + TypeScript (strict)
- Tailwind CSS v4
- vue-echarts
- vue-router, @vueuse/core
- Vitest
